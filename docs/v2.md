# Vexel 2.0 — What's New

Vexel 2.0 keeps the 1.x language intact and adds UI depth, timers,
styles, JSON, projects, and better errors. All snippets below are
complete runnable programs.

## Manual positioning

No forced grid. Every element takes `x`, `y`, `width`, `height`:

```vxl
create a window titled "My App"

button = add a button titled "Click Me"

button.x = 100
button.y = 150
button.width = 200
button.height = 50

window.show
```

Move relative to other elements:

```vxl
create a window titled "My App"

input = add an input box
input.x = 20
input.y = 20
input.width = 200

button = add a button titled "Go"
button.x = input.x
button.y = input.y + input.height + 10

window.show
```

Center in the parent (or window) without math:

```vxl
create a window titled "My App"

button = add a button titled "Go"
button.center
center button in window

window.show
```

Responsive widths without containers:

```vxl
create a window titled "My App"

button = add a button titled "Go"
button.width = 50% of window
set button height to 50 percent

window.show
```

Common mistake: `button.width = 50` is pixels; percent needs `of
window` (assignment) or `percent` (set form).

## Panels, scroll areas, forms

```vxl
create a window titled "My App"

panel = add a panel
panel.width = 300
panel.height = 200

scroll = add a scroll area
form = add a form

name = add an input box to form
email = add an input box to form
submit = add a button titled "Submit" to form

add panel to window

window.show
```

Children use coordinates relative to their parent. Add anything to
a panel, tab page, or the window with `add X to Y`.

## Styles and themes

Bundle looks once, reuse everywhere:

```vxl
create a window titled "My App"

style main_button {
    background = "#202020"
    text_color = "#ffffff"
    font_size = 18
    border_radius = 10
}

button = add a button titled "Go"
button.style = main_button

window.show
```

Themes recolor the whole window. Either syntax works:

```vxl
create a window titled "My App"

use theme "dark"

theme Mono {
    background = "#111111"
    text_color = "#ffffff"
}

set theme to Mono
set theme to "light"

window.show
```

## Events and the event object

More events: `click`, `press`, `release`, `hover`, `enter`,
`leave`, `exit`, `focus`, `blur`, `change`, `key press`,
`key release`, `mouse move`, `mouse down`, `mouse up`,
`mouse enter`, `mouse leave`.

```vxl
create a window titled "My App"

button = add a button titled "Go"

button.on mouse move {
    print event.x
    print event.y
}

button.on mouse enter {
    print "hi"
}

window.show
```

Every handler sees `event`: mouse events carry `event.x`,
`event.y`, `event.button`, `event.target`; key events carry
`event.key`; change events carry `event.value`:

```vxl
create a window titled "Keys"

window.on key press {
    if event.key = "Enter" {
        print "Enter pressed"
    }
}

input = add an input box

input.on change {
    print event.value
}

window.show
```

Common mistake: `event` outside a handler is a compile-time error.

## Timers

Non-blocking timers on the UI loop plus a simple sleep:

```vxl
create a window titled "Clock"

label = add a text titled "waiting..."

every 1 second {
    print "tick"
}

after 5 seconds {
    label.text = "Done"
}

window.show
```

```vxl
print "one"

wait 2 seconds

print "two"
```

`wait` blocks; `every`/`after` never do. Timers need a window.

## Dynamic UI

Change anything at runtime, remove what you no longer need:

```vxl
create a window titled "My App"

button = add a button titled "Loading..."
button.enabled = false

wait 2 seconds

button.title = "Ready"
button.enabled = true
button.visible = false
button.visible = true
button.show
button.hide
button.focus
remove button

window.show
```

`list.clear` empties lists, dropdowns, trees, and tables.

## find and ids

Name elements, then look them up anywhere:

```vxl
create a window titled "My App"

button = add a button titled "Start"
button.id = "startButton"

found = find "startButton"
center found

window.show
```

Duplicate ids are a runtime error. Missing ids fail lookups
loudly instead of returning garbage.

## Dialogs, pickers, clipboard

```vxl
create a window titled "My App"

input = add an input box titled "Type here"

show message "Hello!"
show warning "Something went wrong"

answer = ask "Are you sure?"

if answer {
    print "Confirmed"
}

file = choose a file
folder = choose a folder
color = choose a color

copy "Hello"
copy input.text
text = paste

window.show
```

Pickers return `""` when cancelled, so check before using the
result.

## JSON and objects

Anonymous objects with familiar syntax:

```vxl
data = {
    name = "Zen"
    level = 10
}

print data.name
```

Files, both directions:

```vxl
player = {
    name = "Zen"
    level = 10
    tags = ["hero", "dawn"]
}

json write player to "player.json"

back = json read "player.json"

print back.name
print back.level
```

JSON `null` becomes Vexel `null`:

```vxl
x = null

if x = null {
    print "nothing here"
}
```

## make modes

Convert in place (`upper`/`lower` still work):

```vxl
add input "Enter number:"
set output = value

make value number
print value + 1

ready = "true"
make ready boolean
print ready
```

`make x number` accepts text (or numbers, unchanged) and stores an
integer-or-decimal. `make x string` stringifies anything printable.
`make x boolean` accepts booleans and `"true"`/`"false"`.

## Import aliases

```vxl
import entities/player as player

player.greet
```

Same namespaces, same one-time init, same cycle detection —
just a local nickname.

## Projects and CLI

```bash
vexel create my_app
```

makes `my_app/` with `vexel.project`, `main.vxl`, `src/`,
`assets/`, `libraries/`. Then, inside the folder:

```bash
vexel run      # runs main.vxl (or vexel.project's main)
vexel build    # builds it to a native executable
vexel clean    # removes built executables
```

More commands (dash and no-dash forms both work):

```bash
vexel debug main.vxl   # AST, symbols, types, modules, UI tree
vexel version
vexel help
```

`vexel debug` prints a static analysis view: module graph, AST
node counts, every variable with its inferred type, functions,
structs, components, themes, styles, and — for UI apps — the
widget tree with props and events. Nothing executes.

## Richer errors

`error` is now an object that still prints as its message:

```vxl
try {
    print data/missing.txt
} error {
    print error.message
    print error.type
    print error.file
    print error
}
```

Possible output:

```text
File not found: data/missing.txt
RuntimeError
main.vxl
File not found: data/missing.txt
```

## Calculator walkthrough

The full manual-positioning calculator lives at
`examples/ui/calculator.vxl`: display plus 17 buttons, each placed
with `x`, `y`, `width`, `height`, wired with click handlers,
`number of` conversions, and `try`/`error` around divide-by-zero.

## What 2.0 deliberately leaves out

Networking/HTTP, background threads, and interactive breakpoints
are roadmap items, not 2.0 features: each needs runtime machinery
(timer-based `every`/`after` cover scheduled UI work today).
Fading stays window-only (the backend cannot fade controls), one
window per program, and `opacity` on controls is a compile-time
error rather than a silent lie.

## Vexel 2.2

2.2 changes no syntax and breaks no 2.0/2.1 programs. It pins down
the runtime: exact manual coordinates (zero-padding root, single
DPI scaling), `window.restore`, `window.on resize/move/close`,
cancellable timer handles (`ticker = every 1 second { ... }` plus
`ticker.cancel`), deterministic shutdown (closing the window stops
all live timers), and `vexel debug` geometry with warnings for
overflowing controls, negative sizes, and duplicate ids.
Details: `docs/runtime.md`. Live example: `examples/ui/timers.vxl`.
