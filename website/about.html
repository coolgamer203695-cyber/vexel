About

A language designed to stay simple

Vexel is a general-purpose programming language built on a simple bet: code that reads like plain English is easier to write, review and keep. Simple syntax, strong inferred typing, compiled execution, native-style performance goals, built-in functionality and desktop UI — with minimal unnecessary complexity.

Design principles

Readable first

Words instead of symbols where it counts: and, or, not, repeat, make upper. A Vexel program explains itself to the next person who reads it.

Typed without ceremony

No type declarations to write, no dynamic surprises at runtime. Vexel infers every type, then checks strictly before building.

Compiled to native programs

Vexel source compiles to real executables. What you ship is a program, not a script that needs an interpreter on the target machine.

UI is part of the language

Desktop development is not an ecosystem add-on. Windows, controls, events, timers and dialogs are ordinary Vexel statements.

Errors that teach

Compiler messages say what was expected; runtime errors carry message, type, file, line and column that programs can inspect and report.

Small to learn, honest to use

One project layout, one toolchain, one way to do each thing. Unsupported shapes fail loudly with a reason — never silently, never faked.
