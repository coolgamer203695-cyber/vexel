Version history

Current stable release: Vexel 2.2.0.

Vexel 2.2.0 current

The real-applications release: the desktop UI moved to a new native backend (Avalonia), and the runtime was pinned down and proven with live programs.

  • Multi-window support with per-window size, controls, events and lifecycle
  • Cancellable timer handles (ticker = every 1 second { ... } plus ticker.cancel)
  • Background tasks with pending / running / completed / failed / cancelled states
  • HTTP requests with catchable errors (http get "url")
  • Per-control opacity and non-blocking 60fps animations
  • Exact manual coordinates with parent-relative container children
  • Responsive edge anchoring (b.anchor = "bottom right")
  • Truly modal dialogs, file/folder/color pickers, clipboard round-trip
  • Rich errors: error.message / error.type / error.file / error.line / error.column
  • Project tooling: vexel create / run / build / clean / debug

Vexel 2.0.0

The UI-depth release on top of the 1.x language: manual positioning, new widgets, styles and themes, the event object, timers, JSON, projects and richer errors — with no syntax breaks.

  • Manual positioning (x / y / width / height) and panels, scroll areas, forms
  • Reusable styles and dark / light / custom themes
  • Event object (event.x, event.key, event.value)
  • Timers (every / after / wait) and dynamic show/hide/remove
  • Anonymous objects, JSON read/write, null
  • make x number / string / boolean conversions
  • Import aliases and the project system

Vexel 1.x

The foundation: readable English-like syntax, automatic type inference with strict checking, and native executables. The 1.1 series added native desktop GUI apps — windows, widgets, layouts, styling, events, dialogs and animations — in the same simple style.

  • Console language: variables, conditions, loops, functions, lists, strings, structs, modules, errors
  • Compiled to native executables; running never interprets .vxl line by line
  • 1.1: desktop apps with windows, buttons, inputs, lists, menus, tabs, tables and events
