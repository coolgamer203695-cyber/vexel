VEXEL

Build software with a language designed to stay simple.

Vexel is a readable, English-like programming language. It is strongly typed with automatic type inference, compiled to native executables, and it builds real desktop apps with the same simple syntax.

Why Vexel

Readable first. Simple on purpose.

No parentheses around calls. No semicolons. Types are inferred automatically, then checked strictly before your program ever runs.

Beyond the basics

Made for real programs

Modules

Split code across files with import, share with public, shorten with aliases. Circular imports are rejected.

import entities/player
import entities/player as p

player.greet
p.greet

Events & timers

React to clicks, keys and mouse movement. Run repeating work and delayed actions without blocking.

create a window titled "Clock"

ticker = every 1 second {
    print "tick"
}

ticker.cancel

window.show
