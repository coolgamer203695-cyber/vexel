Install from source today

Vexel runs from its source folder with zero dependencies. Requirements: Node.js 18 or newer and the native compiler toolchain for your system (used by vexel build to produce native executables).

  1. Get the Vexel 2.2.0 source folder on your machine.
  2. Open a terminal inside the vexel folder.
  3. Run node bin/vexel.js --help (Windows: vexel.cmd, Unix: ./vexel). Add the folder to PATH to use the short vexel command.

Verify installation

node --version
vexel version

You should see Node.js 18 or newer, and Vexel 2.2.0.

Running your first program

Save this as hello.vxl:

print "Hello World!"

Then run it:

vexel hello.vxl
vexel check hello.vxl
vexel build hello.vxl

vexel hello.vxl compiles and runs. vexel check verifies types only. vexel build keeps a native executable next to your source. Continue with Lesson 1.
