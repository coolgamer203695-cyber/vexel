Build a Vexel Desktop Hub

Assemble everything from lessons 79–93 into one multi-tab desktop app: calculator, notes, random generator, system utility and about page. Each step below is a complete program — run it before moving on.

Step 1 — Hub shell with five tabs

Window, tab bar, five pages, and an about label. The skeleton every later step grows on.

create a window titled "Desktop Hub"

window.width = 560
window.height = 480

tabs = add a tab bar
tabs.x = 20
tabs.y = 20
tabs.width = 520
tabs.height = 440

calc = tabs.add "Calculator"
notes = tabs.add "Notes"
dice = tabs.add "Random"
system = tabs.add "System"
about = tabs.add "About"

info = add a text titled "Desktop Hub 2.2.0" to about
info.x = 20
info.y = 20
info.width = 400
info.height = 30

motto = add a text titled "Build. Compile. Create." to about
motto.x = 20
motto.y = 60
motto.width = 400
motto.height = 30

window.show

Step 2 — Calculator tab

Display plus 7, + and = with the classic current/first/op state. Digits append, + stores, = computes safely.

create a window titled "Desktop Hub"

window.width = 560
window.height = 480

tabs = add a tab bar
tabs.x = 20
tabs.y = 20
tabs.width = 520
tabs.height = 440

calc = tabs.add "Calculator"
notes = tabs.add "Notes"
dice = tabs.add "Random"
system = tabs.add "System"
about = tabs.add "About"

calcDisplay = add an output box to calc
calcDisplay.x = 20
calcDisplay.y = 20
calcDisplay.width = 440
calcDisplay.height = 60

seven = add a button titled "7" to calc
seven.x = 20
seven.y = 100
seven.width = 130
seven.height = 55

plus = add a button titled "+" to calc
plus.x = 160
plus.y = 100
plus.width = 130
plus.height = 55

equals = add a button titled "=" to calc
equals.x = 300
equals.y = 100
equals.width = 130
equals.height = 55

current = ""
first = ""
op = ""

seven.on click {
    current = current + "7"
    calcDisplay.text = current
}

plus.on click {
    first = current
    op = "+"
    current = ""
    calcDisplay.text = ""
}

equals.on click {
    second = calcDisplay.text
    try {
        f = number of first
        s = number of second
        if op = "+" {
            result = f + s
        } else {
            result = s
        }
        calcDisplay.text = result
        current = calcDisplay.text
    } error {
        calcDisplay.text = error.message
    }
}

window.show

Step 3 — Notes tab

Input, Add button, task list, live count and status line — the lesson-92 pattern parented onto the notes page.

create a window titled "Desktop Hub"

window.width = 560
window.height = 480

tabs = add a tab bar
tabs.x = 20
tabs.y = 20
tabs.width = 520
tabs.height = 440

calc = tabs.add "Calculator"
notes = tabs.add "Notes"
dice = tabs.add "Random"
system = tabs.add "System"
about = tabs.add "About"

taskInput = add an input box titled "New note..." to notes
taskInput.x = 20
taskInput.y = 20
taskInput.width = 280
taskInput.height = 40

addBtn = add a button titled "Add" to notes
addBtn.x = 310
addBtn.y = 20
addBtn.width = 120
addBtn.height = 40

tasks = add a list to notes
tasks.x = 20
tasks.y = 75
tasks.width = 410
tasks.height = 220

countLabel = add a text titled "0 notes" to notes
countLabel.x = 20
countLabel.y = 305
countLabel.width = 410
countLabel.height = 30

count = 0

addBtn.on click {
    if taskInput.text = "" {
        countLabel.text = "Type a note first!"
    } else {
        tasks.add taskInput.text
        count = count + 1
        countLabel.text = "Notes: " + count
        taskInput.text = ""
    }
}

window.show
