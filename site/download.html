Download Vexel

Vexel ships as source you build in minutes — there are no binary installers to trust. You need Node.js 18+ everywhere, plus Rust (console apps) and, on Windows, .NET Framework + csc.exe (already inside Windows 10/11) for GUI apps.

Windows

StepWhat to do
1. Node.jsInstall LTS from nodejs.org, then node --version (≥ 18).
2. RustRun rustup-init.exe from rustup.rs, then rustc --version.
3. GUINothing to install: check C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe exists.
4. VexelCopy the vexel/ folder anywhere, add it to user PATH, open a fresh terminal.
[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";C:\path\to\vexel", "User")
vexel version

Linux

Console programs work today; desktop GUI output targets Windows (WinForms). Install Node.js 18+ and Rust via your package manager and rustup, copy the vexel/ folder, and add it to PATH:

node --version   # needs 18+
rustc --version
export PATH="$PATH:/path/to/vexel"
vexel version

macOS

Same as Linux: Node.js 18+ and Rust, then:

node --version   # needs 18+
rustc --version
export PATH="$PATH:/path/to/vexel"
vexel version
Note: GUI compilation (csc.exe) is Windows-only in 2.0. On Linux/macOS, console programs, check, and the full test suite work; GUI source still type-checks.

First run

vexel hello.vxl        # compile + run
vexel build hello.vxl  # native executable next to the source
vexel check hello.vxl  # type-check only
