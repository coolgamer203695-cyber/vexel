    CLI reference

    CommandDescription
    vexel file.vxlCompile and run a program (console or GUI).
    vexel run [file.vxl]Same; with no file, runs the project entry (./main.vxl).
    vexel build [file.vxl]Compile to a native executable next to the source.
    vexel check file.vxlType-check only, including UI codegen validation.
    vexel debug file.vxlStatic view: AST counts, symbols, types, modules, UI tree. Nothing runs.
    vexel create nameScaffold name/ with vexel.project.
    vexel cleanRemove built .exe files here.
    vexel versionShow the version (also --version).
    vexel helpShow help (also --help).
    $ vexel version
