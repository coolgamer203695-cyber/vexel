Lesson 1 — Hello World

print shows text. No parentheses, no semicolons.

print "Hello World!"
Challenge: print your name on the next line.
Expected result: two lines of output.

Lesson 2 — Variables

Assign and the compiler infers integer, decimal, boolean, string.

name = "Zen"
age = 25
print name
print age + 5
Challenge: store a price (decimal) and print double it.
Expected result: the doubled number.

Lesson 3 — Conditions

age = 18
if age >= 18 {
    print "Adult"
} else {
    print "Child"
}
Challenge: add an else if teenager band (13–17).
Expected result: the right label for 15.

Lesson 4 — Loops

repeat 3 {
    print "Vexel"
}
x = 0
repeat till x = 3 {
    print x
    x = x + 1
}
Challenge: print 10 down to 1 (subtract inside the loop).
Expected result: 10, 9, …, 1.

Lesson 5 — Functions

function greet name {
    print "Hello " + name
}
greet "Zen"
function add a, b {
    return a + b
}
print add 10, 20
Challenge: write square and print square 9.
Expected result: 81.

Lesson 6 — Lists

names = ["Zen", "Alex", "John"]
print names[0]
names[1] = "Mike"
names.add "Sarah"
print names.length
print [2] from names
Challenge: remove index 0, then print the new first item.
Expected result: Mike.

Lesson 7 — Structs

struct Player {
    name
    level
}
hero = Player {
    name = "Zen"
    level = 1
}
hero.level = hero.level + 1
print hero.name
print hero.level
Challenge: add an age field and set it to 25.
Expected result: prints Zen, 2, 25.

Lesson 8 — Modules

Two files. entities/player.vxl (next to your main file):

public name = "Zen"

public function greet {
    print "Hello"
}

Your main file:

import entities/player

print player.name
player.greet
Challenge: add a private function and confirm outside code cannot call it.
Expected result: a visibility error naming the function.

Lesson 9 — Error handling

function divide a, b {
    if b = 0 {
        error "Cannot divide by zero"
    }
    return a / b
}
try {
    print divide 10, 0
} error {
    print error
}
Challenge: also print error.type in the handler.
Expected result: the message, then RuntimeError.

Lesson 10 — GUI

create a window titled "Hello Vexel"

text = add a text titled "Hello World!"

window.show
Challenge: set the window to 500×400 and give the text size 24.
Expected result: a bigger window with big text.

Lesson 11 — Events

create a window titled "Counter"

count = 0
label = add a text titled "Count: 0"
button = add a button titled "Increase"

button.on click {
    count = count + 1
    label.text = "Count: " + count
}

window.show
Challenge: add a second button that subtracts 1.
Expected result: the label goes up and down.

Lesson 12 — Components

create a window titled "Login"

component login_box {
    add a text titled "Login"
    add an input box
    add a button titled "Login"
}

add login_box

window.show
Challenge: stamp login_box twice.
Expected result: two login forms in one window.

Lesson 13 — Build a calculator

Combine input, number of, functions, and try:

add input "First number:"
set output = first
add input "Second number:"
set output = second
try {
    a = number of first
    b = number of second
    print a + b
    print a - b
    print a * b
} error {
    print error
}
Challenge: add division with a divide-by-zero message.
Expected result: correct math, graceful failure on 0.

Lesson 14 — Build a small app

create a window titled "Greeting App"

input = add an input box titled "Your name"
button = add a button titled "Greet"
output = add an output box

button.on click {
    output.text = "Hello " + input.text
}

window.show
Challenge: greet empty input with "Please enter your name."
Expected result: friendly validation, no crash.
