Vexel

Build. Create. Simplify.

A small, readable, English-like programming language that compiles to native executables — console apps and real desktop GUIs. No parentheses. No semicolons.

Install Vexel

You need two free tools first: Node.js 18+ (runs the compiler) and rustc (builds native executables).

Step 1 — Install Node.js

Download the LTS version from nodejs.org, install it, then check:

node --version

Step 2 — Install Rust

On Windows, download and run rustup-init.exe from rustup.rs (accept the defaults). Then check:

rustc --version

macOS / Linux: curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Step 3 — Get Vexel

Copy the vexel folder onto your machine, e.g. C:\Users\You\vexel.

Step 4 — Add Vexel to PATH (Windows)

Run this in PowerShell (replace the path with your real one), then close and reopen the terminal:

[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";C:\Users\You\vexel", "User")

Step 5 — Verify

vexel --version
vexel --help
Tip: if vexel is ever "not recognized", your terminal was opened before PATH changed — open a fresh one. As a fallback you can always run node C:\path\to\vexel\bin\vexel.js ...

Comments & print

Comments start with //. print takes no parentheses and no semicolon:

// This is a comment
print "Hello World!"
name = "Zen"
print name
x = 10
y = 20
print x + y

Variables & types

Just assign — the compiler infers integer, decimal, boolean, or string. Reassigning with a different type is a compile-time error.

name = "Zen"
age = 25
ready = true
price = 19.99
age = "Zen"   // TypeError: cannot assign string to integer

Arithmetic

+ - * / % with normal precedence ((), then * / %, then + -). Division of integers gives a decimal.

x = 10 + 5
y = 20 * 3
z = (100 - 20) / 4
print z
Note: print a / b would be read as a file path (see file reading). Store division in a variable first, or write print (a / b).

Conditions

age = 18
if age >= 18 {
    print "Adult"
} else if age >= 13 {
    print "Teenager"
} else {
    print "Child"
}

Comparisons: == != > < >= <= (a single = also means equality inside conditions).

Logic

English operators, precedence not > and > or:

age = 20
ready = true
if age >= 18 and ready {
    print "Allowed"
}
if not ready {
    print "Not ready"
}

Repeat loops

Vexel has no for/while — it has repeat:

repeat 3 {
    print "Vexel"
}
x = 0
repeat till x = 3 {
    print x
    x = x + 1
}

Functions

No parentheses around parameters or arguments. Arguments must stay on the same line as the function name. Variables created inside a function stay inside it.

function hello {
    print "Hello World!"
}
hello
function greet name {
    print "Hello " + name
}
greet "Zen"
function add a, b {
    return a + b
}
result = add 10, 20
print result
Note: for a negative argument use parens — add (-5), 10 — because a - b is always subtraction.

Lists

names = ["Zen", "Alex", "John"]
print names[0]
names[1] = "Mike"
names.add "Sarah"
names.remove 0
print names.length

Bad indexes are safe runtime errors (catchable with try/error), never crashes.

Strings

name = "zen"
print "Hello " + name
print length of name
print [0] from name
make name upper
print name
make name lower
print name

Structs

Type names start with an uppercase letter. Unknown fields are compile-time errors.

struct Player {
    name
    age
    level
}
hero = Player {
    name = "Zen"
    age = 25
    level = 10
}
print hero.name
hero.level = hero.level + 1
print hero.level

Input & random

Input is always text — convert it with number of before doing math:

add input "First number:"
set output = first
try {
    a = number of first
    print a + 1
} error {
    print error
}
roll = r from 1 to 6
print roll

Error handling

function divide a, b {
    if b = 0 {
        error "Cannot divide by zero"
    }
    return a / b
}
try {
    print divide 10, 0
} error {
    print error
}

Inside the error block, error holds the message. Uncaught errors print to stderr and exit non-zero.

Modules

A file is a module. import executes the module once and exposes only public names through the file's namespace:

// entities/player.vxl
public name = "Zen"
public function greet {
    print "Hello"
}
function secret {
    print "Shh"
}
// main.vxl (same folder as entities/)
import entities/player
print player.name
player.greet
// player.secret  -> VisibilityError: private

File reading

print with a path reads the file. import executes code; print only reads text.

print data/info.txt
try {
    print data/missing.txt
} error {
    print error
}

Exercises (with solutions)

Type each solution into a .vxl file and run it with vexel file.vxl.

1 — Print your name and age from variables 
name = "Ada"
age = 36
print name
print age
2 — Even or odd: use % and if/else 
n = 7
if n % 2 == 0 {
    print "even"
} else {
    print "odd"
}
3 — A square function plus a repeat loop 
function square n {
    return n * n
}
repeat 3 {
    print square 4
}
4 — Guest list: add, remove, print the length 
guests = ["Ada", "Bob"]
guests.add "Cy"
guests.remove 0
print guests[0]
print guests.length
5 — Player struct that levels up twice 
struct Player {
    name
    level
}
hero = Player {
    name = "Zen"
    level = 1
}
repeat 2 {
    hero.level = hero.level + 1
}
print hero.level
6 — Safe divide: function + try/error 
function divide a, b {
    if b = 0 {
        error "Cannot divide by zero"
    }
    return a / b
}
try {
    print divide 10, 0
} error {
    print error
}

FAQ & limitations

Is Vexel interpreted? No. Your .vxl compiles through a real lexer, parser, AST, type checker, and Rust codegen into a native executable via rustc.

Why "Cannot assign string to integer"? Types are inferred from the first assignment and then enforced. Use a new variable name instead.

Why does print a / b fail? A / in print means "file path". Assign first (x = a / b) or use print (a / b).

How do I do math on input? Input is text — wrap it: number of text inside try/error.

Current v0.1 limits: call arguments on one line; struct names Uppercase; / on integers gives decimal; no classes/threads/networking (by design).
