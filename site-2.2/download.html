Get Vexel 2.2.0

One toolchain: edit .vxl files, run them natively, or build shareable apps.

Install

rem Windows — add Vexel to your PATH, then:
vexel version

Expected output: 2.2.0. If the command isn't found, re-open your terminal after install.

Project workflow

vexel project create
vexel run
vexel build
vexel clean
vexel debug hello.vxl
CommandDoes
vexel project createScaffolds vexel.project + folders
vexel runRuns the project natively
vexel buildValidates (parse → UI checks → codegen) and builds
vexel cleanRemoves build artifacts
vexel debugShows AST, symbols, UI tree, tasks, timers, events

Compatibility

2.2 keeps your code working: 2.0/2.1 syntax, semantics, UI code, projects, CLI commands, and standard-library APIs are preserved. Only internals got more reliable.
