Timer with cancellation

timer = every 1 second {
    print "tick"
}

after 5 seconds {
    timer.cancel
}

Background task + safe UI update

go = add a button titled "Load"

go.on click {
    task load_data {
        data = http get "https://example.com/data"
    }
}

The window stays responsive while the request runs; the result is delivered through the UI event queue.
