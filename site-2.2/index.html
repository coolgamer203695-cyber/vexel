What 2.2 guarantees

Same language you know. A runtime you can trust.

Exact coordinates

x, y, width, height are absolute client-area pixels. No hidden stacking, no cumulative offsets.

Multiple windows

Each window owns its controls, events, size, position, and lifecycle. Show, hide, minimize, maximize, close.

Safe background work

Tasks report pending / running / completed / failed / cancelled. UI updates are scheduled onto the UI thread.

Cancellable timers

every and after return handles. timer.cancel really stops them and frees resources.

Clean shutdown

Quit stops timers, cancels tasks, closes windows, releases resources — deterministically.

Rich diagnostics

Compiler and runtime errors carry type, file, line, column, source excerpt, and a plain-English explanation.

The positioning promise

Four buttons, one row, no surprises:

a.x = 20    b.x = 100   c.x = 180   d.x = 260
a.y = 20    b.y = 20    c.y = 20    d.y = 20
+--------------------------------------+
|  [A]    [B]    [C]    [D]                   |
+--------------------------------------+
Rule: explicit x/y wins. Containers only lay out children when you explicitly create one. Backends never override you silently.

Lifecycle at a glance

Program starts → Runtime init → Modules init → UI init → Event loop
  → Tasks / timers / events → App closes → Cancel tasks → Stop timers
  → Close windows → Release resources → Shutdown
